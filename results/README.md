# Runs & experiment evidence

Chỉ thêm kết quả **thực tế** và **đã hoàn thành**, có thể lặp lại. Ghi vào `run-registry.csv` và cập nhật bảng mapping trong README gốc.

Cột CSV:
- `experiment_id`: EXP-01 / EXP-02 / EXTRA-01, ...
- `script`: lệnh/script thực sự đã chạy.
- `wandb_run_url`: link run công khai; không phải project URL chung.
- `summary`: mô tả một dòng dựa trên kết quả thật.
- `seed`: seed thực tế.
- `status`: finished / failed (chỉ lấy giá trị thật).

Hiện tại file CSV mới có header; **chưa có run nào**.
